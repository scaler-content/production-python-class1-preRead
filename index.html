2. What is Python?

Python is a programming language: a way of writing instructions that a computer can follow. It is known for being readable. Python code often looks close to plain English, which is one reason it is so popular for data work, automation and AI.

You write instructions in text, and a program called the Python interpreter reads them and carries them out, one step at a time.

If you already know another language

Some of you may have used Java, C, JavaScript or another language. Python does a few things differently. These differences cause the most surprises, so here they are up front.

IdeaMany other languagesPython
Grouping code into blocksCurly braces { }Indentation (spaces at the start of a line)
End of a statementSemicolon ;Just the end of the line
Declaring a variable's typeint x = 5;Not needed. x = 5
Comments// note or /* note */# note
Running codeOften compiled firstRead and run directly by the interpreter
Capital lettersUsually matterAlways matter: Name and name are different

The two big ones, indentation and no type declarations, get their own interactive demos in Section 7.

Two things to remember In Python, indentation is part of the grammar, not decoration. And you do not declare types; Python works them out from the value you give it.

5. The terminal

VS Code has a terminal built in, so you already met one in Section 4. This section explains what it is and what to type in it.

What is a terminal?

Most of the time you use your computer by clicking: you open a folder, double-click a file, press a button. A terminal is another way. It is a plain text window where you type instructions and the computer answers in text.

Why use it? Because many developer tools, including Python, are built to be used this way. Typing a command is quick, exact and repeatable. A command you type today works the same way tomorrow, and you can share it with a colleague.

How it works

A terminal does one thing, over and over: it waits for you, runs what you typed, shows the result and waits again.

1. PromptThe terminal waits and shows a prompt
→
2. You typeA command, then press Enter
→
3. It runsThe computer carries it out
→
4. OutputThe result is printed, then a new prompt

Here is a real line, colour-coded:

learner@laptop:~$python --version
Python 3.12.3

Blue-grey is the prompt (the terminal is ready; yours will look a little different). Green is the command you type. The grey box underneath is the output.

One idea to hold on to: you are always "in" a folder

A terminal is always working from one folder, called the current folder (or working directory). When you run a command that mentions a file, the computer looks for that file in the current folder. This is why "file not found" errors usually just mean "you are in a different folder than you think".

How to open a terminal

Press the Windows key, type PowerShell (or Terminal on Windows 11), and press Enter.

Press Command + Space, type Terminal, and press Enter. Or open Finder, then Applications, then Utilities, then Terminal.

Press Ctrl + Alt + T on most systems. Or open the applications menu and search for Terminal.

In VS Code, choose Terminal from the menu, then New Terminal. The shortcut is Ctrl + ` (the key under Esc). It opens already inside your project folder, which is why we use it in class. Set up VS Code in Section 4.

6. Two ways to run Python: a file, and the REPL

You can give Python instructions in two different ways. You will use both in this course.

Way 1: a Python file (a script)

A Python file is a text file whose name ends in .py. You write several instructions in it, save it, and ask Python to run the whole file from top to bottom. Here is the smallest useful one. It has two lines, and the first starts with #, which makes it a comment that Python ignores.

hello.py
# My first Python file
print("Meridian case batch received")

To run it, open a terminal in the folder that contains the file and type. In VS Code, that is Terminal, then New Terminal, as you did in Section 4. Remember to save the file first.

python hello.py

# Output:
# Meridian case batch received

print(...) tells Python to show something on the screen. A file is saved, repeatable and shareable. Everything you build in this course will live in files.

Way 2: the REPL

The second way is to talk to Python directly, one line at a time, without making a file. This is called the REPL (say "reh-pul").

What is the REPL, really?

REPL is short for Read, Eval, Print, Loop. Each word is one step of what Python does every time you type something:

ReadPython reads the line you typed
→
EvalIt works out ("evaluates") what the line means
→
PrintIt shows you the result
→
LoopIt goes back and waits for your next line

The easiest way to picture it is a conversation. You say one sentence, Python answers straight away, then it waits for your next sentence. A file, by contrast, is like writing a whole letter and posting it in one go.

  • It answers immediately. You see the result of each line as soon as you press Enter.
  • It remembers. If you store a value on one line, you can use it on a later line, for as long as the REPL stays open. When you close it, the memory is gone.
  • Mistakes are cheap. If you type something wrong, Python shows an error and gives you a new prompt. Nothing breaks, and the REPL keeps going.
  • It is a scratchpad. Nothing is saved. That makes it perfect for trying an idea quickly before putting it into a file.
Python fileThe REPL
How you use itWrite many lines, run them allType one line at a time
Result appearsWhen the whole file runsAfter every line
Saved?YesNo
Best forReal programs you will keep and reuseTrying things, checking an idea, learning

How to start and leave the REPL

In a terminal, type python (or python3 on Mac and Linux, or py on Windows) and press Enter, with no file name. You will see some text and then a new prompt that looks like >>>. That prompt means "Python is listening". To leave, type exit() and press Enter. You are back at the terminal's own prompt.

Two prompts, two different things The terminal's prompt (like learner@laptop:~$) waits for terminal commands. The REPL's prompt >>> waits for Python code. Typing Python at the terminal prompt, or a terminal command at >>>, will give an error. When something confusing happens, look at the prompt and ask yourself which one you are talking to.

6.2 You do not declare types

In languages like Java or C, you must say what kind of value a variable will hold before you use it, and it cannot change. In Python, you just give the variable a value, and Python works out the type for you. The same name can even point to a different kind of value later.

Java / C style

int x = 5;
x = "five";   // error: x must be an int

Python

x = 5
x = "five"    # fine

6.4 The built-in data structures

A data structure holds more than one value. Python has four built-in ones that you will use all the time. The brackets are how you tell them apart.

List: an ordered collection you can change. Items are read by position, and counting starts at 0.

statuses = ["SHIPPED", "DELIVERED", "PROCESSING"]
statuses[0]                 # 'SHIPPED'  (the first item)
statuses.append("CANCELLED")  # add an item to the end
len(statuses)               # 4

Tuple: an ordered collection that cannot be changed after you create it. Good for values that belong together, like a pair.

pair = ("C-1002", "O-5002")
pair[0]                     # 'C-1002'
# pair[0] = "C-9999"        # error: a tuple cannot be changed

Dictionary: labelled values, written as key: value pairs. You read a value by its key, not by position. A real case in this course will look like this.

case = {"case_id": "C-1002", "order_status": "SHIPPED"}
case["order_status"]        # 'SHIPPED'
case["note_id"] = "N-01"    # add a new key and value

Set: a collection of unique values with no repeats and no fixed order. Good for "is this value in the group?".

closed = {"DELIVERED", "CANCELLED", "DELIVERED"}
len(closed)                 # 2  (the repeat disappeared)
"DELIVERED" in closed       # True

Careful: {} on its own is an empty dictionary. An empty set is written set().
